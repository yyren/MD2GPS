### Docker images used by MD2GPS
MD2GPS requires four Singularity images. Please download them from the BMAP software repository and place them in the Docker_image folder while keeping their original filenames. <br>

The images and their download links are as follows:
ubuntu1604_py3_VCF.sif: https://bmap.sjtu.edu.cn/softstorage/details/54<br>
ubuntu2004_Rank.sif: https://bmap.sjtu.edu.cn/softstorage/details/56<br>
ubuntu2004_MD2GPS.sif: https://bmap.sjtu.edu.cn/softstorage/details/55<br>
ubuntu2004_MT.sif: https://bmap.sjtu.edu.cn/softstorage/details/57<br>
After downloading, verify that the files are correctly placed in the Docker_image folder and that Singularity is properly installed on your system.
